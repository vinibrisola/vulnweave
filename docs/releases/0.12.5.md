# VulnWeave 0.12.5

## Remediation sandbox isolation

The packaged 0.12.5 build includes a fix intended to keep generated scanner-report artifacts from contaminating candidate and baseline sandbox copies used during remediation validation.

The security model remains fail-safe: dependency resolution, build, tests, rescan and `readyToApply` gates are not relaxed.

## Source provenance note

The supplied public-source archive is 0.12.4. The exact 0.12.5 native-engine/JetBrains source used for the uploaded binaries was not supplied, so this repository records the difference explicitly instead of relabeling older source.
